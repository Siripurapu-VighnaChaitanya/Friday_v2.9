Startup Sequence

How to boot and authenticate Friday each session

1

Run the program

Open your command line/terminal and execute the following command in the virtual environment:

python main.py
2

Say the wake word

Speak clearly to trigger wake word detection (monitored by the background listener):

hello fridayhi fridayhey fridayok fridayfriday
3

Say the security code (0010)

Authenticate yourself by speaking the correct passcode when Friday prompts you:

0010zero zero one zerodouble zero one zero001
4

Choose your voice language

State one of the supported languages when prompted by Friday:

englishteluguhindi
Security Authentication Note: The security code verification is active. You have 3 attempts to speak the correct passcode (0010) before Friday locks and returns to sleep mode.
